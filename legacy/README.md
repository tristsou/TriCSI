# Historical utilities

These files were moved from the root and recovered experiment-kit directories
without changing their bytes. They provide research history and optional tools;
they are not the reader's starting workflow. Use the root README and supported
`python -m tricsi` interface first.

| Folder | Historical purpose |
| --- | --- |
| `scripts` | Earlier collectors, baselines, transfer diagnostics and live demos |
| `windows` | Older batch launchers, whose embedded relative paths are historical |
| `TriCSI_review_response` | Review controls and replication utilities |
| `TriCSI_six_model_study` | Follow-up study toolkit and reference copies |
| `TriCSI_One_Day_Code` | Previous short experiment workflow |
| `TriCSI_ABBA_Experiment_Kit` | Previous ABBA collection/analysis kit |
| `python_utils` | Earlier serial/plot tools |
| `analysis` | Earlier analysis scripts |

[Migration map](../metadata/migration.json) records old/new paths and file hashes.
Supported descriptive scripts in `workflows` resolve that map and set import paths.
Old embedded documentation, hardcoded paths and direct batch invocations are not
guaranteed against the new layout. They remain untouched to preserve provenance.
